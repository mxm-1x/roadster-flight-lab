# Aceternity UI components

These components were downloaded from Aceternity UI's public registry and are
included as source in `src/components/ui/`:

- Bento Grid: https://ui.aceternity.com/components/bento-grid
- Spotlight: https://ui.aceternity.com/components/spotlight
- Glowing Effect: https://ui.aceternity.com/components/glowing-effect

Registry author: Manu Arora / Aceternity UI. These free components are integrated
with React, Tailwind CSS and Motion. Glowing Effect uses its `white` variant;
the application respects reduced motion preferences. Component source files
include their original URLs. Layout, typography, charts, data handling and the
training/replay interfaces are specific to Landing Lab.
